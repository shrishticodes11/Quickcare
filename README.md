# 🏥 QuickCare – Hospital Finder

QuickCare is a hospital finder project that helps users find hospitals based on their city and specialty. It also provides hospital details, available beds, emergency hospital search, and hospital locations using Google Maps.

## ✨ Features

- 🔐 Simple login page
- 🏥 Search hospitals by city and specialty
- ⭐ Hospital ratings and reviews
- 🛏️ Available bed information
- 🚑 Emergency hospital finder
- 📍 View hospital locations on Google Maps
- 💻 Responsive and user-friendly interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Java Swing
- Google Maps

## 📂 Project Structure

- `index.html` – Login page
- `quickcare.html` – Main hospital finder page
- `style.css` – Styling and UI
- `script.js` – Hospital search and interactive features
- `QuickCareSwing.java` – Java Swing version of the hospital finder

## 🚀 How to Run

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. Log in using the credentials provided in the project.
4. Explore the hospital finder and other features.
